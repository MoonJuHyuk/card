# 우리집 카드 정산 작업안내서

나중에 고칠 때 이 문서부터 보세요. 진행 기록은 `docs/진행사항.md`에 있습니다.

## 1. 한눈에 보기

| 항목 | 위치 |
|---|---|
| 앱 주소 (폰 홈 화면에 설치) | https://moonjuhyuk.github.io/card-settlement/ |
| 코드 원본 | NAS 작업 폴더(경로는 `docs/연결정보.local.md`) = GitHub `MoonJuHyuk/card-settlement` (공개, 코드만) |
| 데이터 | 구글시트 **우리집 카드 정산**, 탭 `내역` |
| 저장 서버 | 시트에 붙은 Apps Script (확장 프로그램 → Apps Script), 웹 앱으로 배포 |
| 비밀 정보 (시트 주소·웹 앱 주소·연결 링크) | `docs/연결정보.local.md` — NAS에만 있고 GitHub에는 올리지 않음 |

## 2. 동작 구조

```
폰/PC 브라우저 (GitHub Pages의 앱 화면)
   └─ 목록 읽기·직접 추가 → 구글시트 Apps Script 웹 앱 (비밀키로 보호)
                               └─ 시트 '내역' 탭
카드 정산(새 내역 추가) → Claude가 카드사 사이트에서 가져와 시트에 직접 추가
```

- 앱은 열 때마다 시트의 내역을 전부 읽어 와서 화면에서 계산합니다. 시트를 고치면 다음에 열 때 반영됩니다.
- 마지막으로 불러온 내역은 기기에 저장돼 있어서 인터넷이 끊겨도 보입니다.
- 연결 링크를 연 기기만 내역을 읽을 수 있습니다. 링크가 새어 나가면 Apps Script에서 `resetSecret` 실행 → `connectLink`로 새 링크.

## 3. 시트 열 순서 (`내역` 탭)

| 열 | 내용 | 비고 |
|---|---|---|
| A | 날짜 | yyyy-mm-dd |
| B | 가맹점 | |
| C | 항목 | 배달, 외식·술, 카페·간식, 장보기·생활, 교통, 자동차·충전, 자동차 구매, 주거·관리비, 의료·약국, 미용, 백화점·쇼핑, 여가·문화, 연회비, 기타, ○○여행 |
| D | 금액 | 원 |
| E | 사용자 | 앱의 '둘 다 / ○○' 버튼이 이 값으로 생깁니다 |
| F | 카드 | 카드사 이름, 현금 … |
| G | 상태 | 청구(명세서 반영) / 승인(미청구) / 직접입력 |
| H | 메모 | 외화 금액 등 |

- 이름에 '여행'이 들어간 항목과 '자동차 구매'는 '생활비'에서 빠집니다.
- 열 순서를 바꾸면 안 됩니다. 칸을 추가하려면 `Code.gs`의 `FIELDS`와 `js/app.js`를 같이 고치세요.

## 4. 고칠 때 순서

### 앱 화면만 고칠 때
1. NAS 폴더의 파일 수정
2. `js/app.js`와 `sw.js`의 `VERSION`을 함께 올리기
3. GitHub에 올리기 → 1~2분 뒤 앱 주소에 반영. 폰은 앱을 열면 새 버전을 받아 한 번 새로고침함

### 저장 스크립트(Code.gs)를 고칠 때
1. `apps-script/Code.gs` 수정
2. 시트 → 확장 프로그램 → Apps Script에 같은 내용 붙여넣고 저장
3. 배포 → 배포 관리 → 연필(편집) → 버전 '새 버전' → 배포 (주소 그대로). '새 배포'는 주소가 바뀌니 쓰지 않기

### 카드 정산(새 내역 추가)
- Claude에게 "카드 정산해줘". 카드사 사이트에 로그인만 해 두면, 시트의 마지막 날짜 이후 내역을 가져와 `내역` 탭 아래에 붙입니다.
- 명세서가 나온 달은 명세서(청구액) 기준으로, 아직 청구 전인 달은 승인 내역으로 넣고 상태 칸에 표시합니다. 다음 정산 때 '승인(미청구)' 줄은 명세서 금액으로 바꿉니다.

## 5. 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 고쳤는데 폰에 안 바뀜 | `VERSION` 두 곳을 올렸는지. 앱을 닫았다 다시 열기 |
| '연결이 끊겼습니다' | 비밀키를 바꿨는지(`resetSecret`). 새 연결 링크로 다시 열기 |
| 내역이 안 불러와짐 | 웹 앱 배포가 '실행: 나, 액세스: 모든 사용자'인지 |
