# 진행사항

## 2026-11-10 — v0.4.0 고정비
- 고정비 = 보험, 주거·관리비, 회비 항목 (`FIXED_CATS`). 생활비에 포함된 채로 따로 보여줌
- 전체 화면: 고정비 월평균 칸, 고정비 카드(내용별 월평균·지난달·최근 결제일)
- 월별 화면: 생활비를 고정비 + 그 외로 나눠 표시, 마지막 달은 지난달엔 있었는데 아직 안 나간 고정비를 표시

## 2026-11-10 — v0.3.0 내역 고치기·지우기
- 이용내역에서 줄을 누르면 날짜·내용·금액·항목·누가·결제수단·메모를 고치거나 지울 수 있음. 항목은 목록에서 고르거나 새 항목을 만들 수 있음
- 저장 스크립트에 `update`, `delete` 추가. 앱이 본 줄과 시트의 줄이 다르면(그 사이 줄이 밀리면) 거부
- 생활비 계산에서 `결혼식` 항목도 제외

개인 정산 기록(기간·건수·금액 등)은 공개 저장소에 적지 않고 NAS의 `docs/연결정보.local.md`에만 적습니다.

## v0.1.0 첫 버전
- 앱: 전체·월별 탭, 사람별 보기, 월별·항목별·날짜별 차트, 월별 항목 비교표, 큰 지출, 검색, 현금 등 직접 추가, 오프라인 보기
- 구조: GitHub Pages 화면 + 구글시트 Apps Script(비밀키로 보호)
- '여행'이 들어간 항목과 '자동차 구매'는 생활비 계산에서 제외
