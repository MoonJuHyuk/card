# 우리집 카드 정산

부부가 함께 보는 카드 지출 정산 앱입니다. 카드 내역은 각자의 구글시트에 저장되고, 이 앱은 그 시트를 읽어 전체·월별로 정리해 보여줍니다.

- 폰 홈 화면에 설치하는 웹앱(PWA). 인터넷이 끊겨도 마지막으로 불러온 내역을 볼 수 있습니다.
- 전체 / 월별 탭, 월별·항목별 차트, 월별 항목 비교표, 큰 지출, 날짜별 사용액, 검색
- 사람별(예: 남편 / 아내) 보기
- 현금 지출 등 직접 추가

## 구조

```
index.html              화면 뼈대
css/app.css             디자인
js/app.js               화면 동작, 구글시트 연결
sw.js                   오프라인용 서비스 워커
apps-script/Code.gs     구글시트에 붙이는 저장 스크립트
```

빌드 과정이 없는 순수 HTML·JS입니다. PC에서 미리 보려면 `run-local.bat`을 실행합니다.

## 개인정보

내역 데이터는 이 저장소에 없습니다. 사용자 본인의 구글시트에만 있고, 연결 링크(비밀키)를 연 기기만 읽을 수 있습니다.
